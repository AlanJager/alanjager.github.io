# 开源工具入口维护

本站当前发布源是 `github_pages` 分支的静态文件。本次复用现有 Hexo 主题导航、文章容器及样式，没有新依赖。

用户路径：首页/文章/归档（桌面或移动导航）→ 工具 → /tools/ → 项目页 / GitHub / 返回博客。

已发布：

- `/tools/resume-hub/` — Codex/Claude/Grok session 交接 skill + CLI（MIT，仅该子目录）

以后从 Hexo 源项目重新生成时需同步：

1. 在实际使用的主题配置 `menu` 加 `Tools: /tools/`，确保桌面与移动端菜单一致。
2. 把 tools/index.html 的正文移入 Hexo 源项目的工具目录页，保留 `/tools/` 路径，勿把本站生成文件当唯一源稿。
3. 新工具代码的许可证以各自子目录 LICENSE 为准；博客已有文章许可不自动适用于独立软件。

本仓库没有当前 Hexo 源项目及构建配置，所以本次直接维护实际发布内容。后续重新生成时如未同步以上项目，会覆盖入口修改。
